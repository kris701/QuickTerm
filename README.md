# QuickTerm

A small program that allows you to run small predefined commands from your taskbar.
It features:
* Fully configurable command menu
* CMD and Powershell terminal types
* Automatic updates
* Auto run on startup
* Small binary size
* Simple to use : )

You can download the latest version under [Releases](https://github.com/kris701/QuickTerm/releases/latest).
Simply download the "QuickTerm.exe" file and start it.
It will pop up with the config window as long as there are no command nodes made.

When you save, a config file in a simple JSON format is made next to the exe file.
